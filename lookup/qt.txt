.moc stands for Meta-Object Compiler - it's a preprocessor tool that generates C++ code from Qt-specific extensions.
When MOC is Needed	Q_OBJECT  // ← Requires MOC
	    Q_OBJECT  // ← Requires MOC if using signals/slots
	    Q_PROPERTY(int value READ value WRITE setValue)  // ← Requires MOC

MOC vs Other Preprocessors
Feature		MOC				Regular C++ Preprocessor
Purpose		Qt meta-object generation	Text replacement
Input		Header files with Qt macros	Any C++ file
Output		C++ code (.cpp)			Processed source
Timing		Before compilation		Before compilation
Handles		Q_OBJECT, signals, slots	#define, #include, #ifdef
