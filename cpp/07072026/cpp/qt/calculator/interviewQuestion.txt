Q1: How would you architect this calculator application for scalability?

Answer:
text

I would follow a Model-View-Controller (MVC) or Model-View-ViewModel (MVVM) architecture:

Model Layer:
- CalculatorEngine class: Handles all calculations, business logic
- HistoryModel: Manages calculation history
- MemoryModel: Handles memory operations (M+, M-, MR, MC)

View Layer:
- CalculatorWidget: UI layout (buttons, displays)
- Custom widgets: Digital display, button groups

Controller/ViewModel Layer:
- CalculatorController: Connects UI events to model operations
- State management: Current operation, pending operands

This separation allows:
- Unit testing of business logic without UI
- Easy addition of new features (scientific mode, history)
- Multiple views (console, GUI, mobile) with same backend

    QQueue<QString> toPostfix(const QString& expr) {
        QStack<QString> opStack;
        QQueue<QString> output;
        
        for (auto token : tokenize(expr)) {
            if (isNumber(token)) {
                output.enqueue(token);
            } else if (isOperator(token)) {
                while (!opStack.isEmpty() && 
                       precedence(opStack.top()) >= precedence(token)) {
                    output.enqueue(opStack.pop());
                }
                opStack.push(token);
            } else if (token == "(") {
                opStack.push(token);
            } else if (token == ")") {
                while (!opStack.isEmpty() && opStack.top() != "(") {
                    output.enqueue(opStack.pop());
                }
                opStack.pop(); // Remove '('
            }
        }
        return output;
    }
    
    double evaluatePostfix(QQueue<QString>& postfix) {
        QStack<double> stack;
        while (!postfix.isEmpty()) {
            QString token = postfix.dequeue();
            if (isNumber(token)) {
                stack.push(token.toDouble());
            } else if (isOperator(token)) {
                double b = stack.pop();
                double a = stack.pop();
                stack.push(applyOperator(a, b, token));
            }
        }
        return stack.pop();
    }

🎯 SIGNAL/SLOT MECHANISM QUESTIONS
Q4: Explain the signal/slot mechanism in detail.

Answer:
text

Signal/Slot is Qt's implementation of the Observer pattern, allowing loose 
coupling between objects.

Key Concepts:
1. Signals: Events that can be emitted by objects
   - Declared with 'signals:' keyword
   - No implementation required
   - Can be connected to multiple slots

2. Slots: Functions that handle signals
   - Declared with 'public slots:' or 'private slots:'
   - Normal functions that can be called directly
   - Can be connected to multiple signals

3. Connection Types:
   - Direct: Called immediately when signal emitted
   - Queued: Called when event loop returns
   - BlockingQueued: Blocks sender until slot executed
   - Auto: Qt chooses based on thread affinity
   - UniqueConnection: Prevents duplicate connections

4. Under the Hood:
   - MOC (Meta-Object Compiler) generates meta-data
   - Signal is a function pointer array
   - Slot is a normal function with meta-data
   - Connection stores sender, receiver, signal, slot indices

5. Performance:
   - Direct connection: ~4x slower than function call
   - Queued connection: ~50x slower
   - Use direct connection for performance-critical code

💾 MEMORY MANAGEMENT QUESTIONS
Q6: How do you manage memory in Qt applications?

Answer:
text

Qt uses parent-child ownership model:

1. Parent-Child Relationship:
   - Setting parent when creating widget
   - Parent automatically deletes children
   - Use `setParent()` or pass parent in constructor

2. Smart Pointers:
   - QScopedPointer: For exclusive ownership
   - QSharedPointer: For shared ownership
   - QWeakPointer: For weak references

3. Memory Management Strategies:
   a. Widget Tree:
      QWidget* parent = new QWidget();
      QPushButton* button = new QPushButton(parent);
      // button automatically deleted when parent deleted

   b. RAII Pattern:
      QScopedPointer<QFile> file(new QFile("data.txt"));
      // Auto-deleted when out of scope

   c. QObject::deleteLater():
      // Safe deletion during event loop
      obj->deleteLater();

4. Common Pitfalls:
   - Double deletion: Don't manually delete if parent owns
   - Memory leaks: Properly delete dynamic objects
   - Cyclic references: Use QWeakPointer to break cycles

Implementation in Calculator:

Q8: How does the event loop work in Qt?

Answer:
text

Qt Event Loop (QEventLoop) processes events in a queue:

1. Basic Flow:
   while (true) {
       event = dequeueEvent();
       if (event == nullptr) {
           waitForEvents();
           continue;
       }
       processEvent(event);
       if (shouldQuit) break;
   }

2. Event Types:
   - QEvent::MouseButtonPress
   - QEvent::KeyPress
   - QEvent::Paint
   - Custom events (QEvent::User + value)

3. Event Filters:
   bool eventFilter(QObject* obj, QEvent* event) override {
       if (event->type() == QEvent::KeyPress) {
           QKeyEvent* keyEvent = static_cast<QKeyEvent*>(event);
           // Handle key press
           return true;  // Consume event
       }
       return QObject::eventFilter(obj, event);
   }

4. Event Propagation:
   - Widget receives event
   - Process event
   - Propagate to parent
   - Filter with event filters

5. Custom Events:
   class CalculatorEvent : public QEvent {
   public:
       CalculatorEvent(EventType type) 
           : QEvent(QEvent::User + 1), m_type(type) {}
       EventType type() const { return m_type; }
   private:
       EventType m_type;
   };

6. Threading:
   - Main thread = GUI thread
   - Worker threads can post events using QCoreApplication::postEvent()
   - Use QMetaObject::invokeMethod() for cross-thread calls

Q9: What is the Meta-Object System and how does it work?

Answer:
text

Meta-Object System provides runtime information about objects:

1. Components:
   - QObject: Base class for all meta-object enabled objects
   - Q_OBJECT Macro: Enables meta-object features
   - MOC: Preprocessor that generates meta-object code

2. Features Enabled:
   - Signals/Slots
   - Runtime type information (qobject_cast)
   - Dynamic properties
   - Qt's event system
   - QML integration
   - Translation (tr())

3. Meta-Object Data:
   - Class name
   - Superclass
   - Signals (method signatures)
   - Slots (method signatures)
   - Properties

4. Working Mechanism:
   // myclass.h
   class MyClass : public QObject {
       Q_OBJECT
       Q_PROPERTY(int value READ value WRITE setValue)
   public:
       int value() const;
       void setValue(int v);
   signals:
       void valueChanged(int newValue);
   };

   // MOC generates:
   static const qt_meta_stringdata_MyClass_t 
       qt_meta_stringdata_MyClass = {
           {
               QT_MOC_LITERAL(0, 0, 7),  // "MyClass"
               QT_MOC_LITERAL(1, 8, 12), // "valueChanged"
               QT_MOC_LITERAL(2, 21, 1)  // "newValue"
           },
           "MyClass\0valueChanged\0newValue"
       };

5. Runtime Usage:
   const QMetaObject* meta = obj->metaObject();
   QMetaProperty prop = meta->property(meta->indexOfProperty("value"));
   prop.write(obj, QVariant(42));

6. Performance:
   - MOC adds about 10-20% overhead
   - Signal/Slot connections are type-safe
   - Can be slower than direct function calls
   - Optimized for GUI applications

💻 C++ QUESTIONS
Q10: Explain the rule of three/five/zero in the calculator.

Answer:
text

Rule of Three (C++98):
- If you define one of: destructor, copy constructor, copy assignment
- You should define all three

Rule of Five (C++11):
- Adds: move constructor, move assignment operator

Rule of Zero (C++11+):
- Prefer not to define any special member functions
- Use RAII classes (smart pointers, containers)

Implementation in Calculator:

// Rule of Three/Five Example
class CalculatorEngine {
public:
    CalculatorEngine() : m_data(new double[100]) {}
    
    // Destructor
    ~CalculatorEngine() { delete[] m_data; }
    
    // Copy Constructor
    CalculatorEngine(const CalculatorEngine& other) 
        : m_data(new double[100]) {
        std::copy(other.m_data, other.m_data + 100, m_data);
    }
    
    // Copy Assignment
    CalculatorEngine& operator=(const CalculatorEngine& other) {
        if (this != &other) {
            double* newData = new double[100];
            std::copy(other.m_data, other.m_data + 100, newData);
            delete[] m_data;
            m_data = newData;
        }
        return *this;
    }
    
    // Move Constructor (C++11)
    CalculatorEngine(CalculatorEngine&& other) noexcept 
        : m_data(other.m_data) {
        other.m_data = nullptr;
    }
    
    // Move Assignment (C++11)
    CalculatorEngine& operator=(CalculatorEngine&& other) noexcept {
        if (this != &other) {
            delete[] m_data;
            m_data = other.m_data;
            other.m_data = nullptr;
        }
        return *this;
    }
    
private:
    double* m_data;
};

// Rule of Zero Example
class ModernCalculatorEngine {
public:
    // Use smart pointers - no manual memory management
    ModernCalculatorEngine() 
        : m_data(std::make_unique<std::vector<double>>()) {}
    
    // All special member functions are auto-generated
    // and correctly implemented by the compiler
    
private:
    std::unique_ptr<std::vector<double>> m_data;
};

class Command {
public:
    virtual ~Command() = default;
    virtual void execute() = 0;
    virtual void undo() = 0;

};

class AddNumberCommand : public Command {
public:
    AddNumberCommand(Calculator* calc, const QString& number)
        : m_calc(calc), m_number(number), m_prevDisplay(calc->displayText()) {}
    
    void execute() override {
        m_calc->appendNumber(m_number);
    }
    
    void undo() override {
        m_calc->setDisplay(m_prevDisplay);
    }
    
    QString description() const override {
        return "Add digit: " + m_number;
    }
    
private:
    Calculator* m_calc;
    QString m_number;
    QString m_prevDisplay;
};

class CalculatorCommandHistory {
public:
    void execute(std::unique_ptr<Command> cmd) {
        cmd->execute();
        m_undoStack.push_back(std::move(cmd));
        // Clear redo stack
        m_redoStack.clear();
    }
    
    void undo() {
        if (!m_undoStack.isEmpty()) {
            auto cmd = std::move(m_undoStack.last());
            m_undoStack.removeLast();
            cmd->undo();
            m_redoStack.append(std::move(cmd));
        }
    }
    
    void redo() {
        if (!m_redoStack.isEmpty()) {
            auto cmd = std::move(m_redoStack.last());
            m_redoStack.removeLast();
            cmd->execute();
            m_undoStack.append(std::move(cmd));
        }
    }
    
private:
    QList<std::unique_ptr<Command>> m_undoStack;
    QList<std::unique_ptr<Command>> m_redoStack;
};

class CalculationStrategy {

// Concrete Strategies
class AdditionStrategy : public CalculationStrategy {
public:
    double calculate(double a, double b) override { return a + b; }
    QString name() const override { return "Addition"; }
};

class SubtractionStrategy : public CalculationStrategy {
public:
    double calculate(double a, double b) override { return a - b; }
    QString name() const override { return "Subtraction"; }
};

class MultiplicationStrategy : public CalculationStrategy {
public:
    double calculate(double a, double b) override { return a * b; }
    QString name() const override { return "Multiplication"; }
};

class DivisionStrategy : public CalculationStrategy {
public:
    double calculate(double a, double b) override {
        if (b == 0) throw std::runtime_error("Division by zero");
        return a / b;
    }
    QString name() const override { return "Division"; }
};

// Calculator with Strategy
class CalculatorWithStrategy {
public:
    void setStrategy(std::unique_ptr<CalculationStrategy> strategy) {
        m_strategy = std::move(strategy);
    }
    
    double compute(double a, double b) {
        if (!m_strategy) {
            throw std::runtime_error("No strategy set");
        }
        return m_strategy->calculate(a, b);
    }
    
    QString currentStrategyName() const {
        return m_strategy ? m_strategy->name() : "None";
    }
    
private:
    std::unique_ptr<CalculationStrategy> m_strategy;
};

Q17: How would you optimize the calculator for 1000 operations?

class OptimizedCalculator {
public:
    OptimizedCalculator() {
        // Pre-allocate memory
        m_results.reserve(1000);
        m_operations.reserve(1000);
    }
    
    double processBatch(const QList<Operation>& operations) {
        QElapsedTimer timer;
        timer.start();
        
        // Batch processing
        for (const auto& op : operations) {
            // Use efficient calculation
            double result = calculateOptimized(op);
            m_results.append(result);
            m_operations.append(op);
        }
        
        return timer.elapsed();
    }
    
    // Use move semantics for efficiency
    void addOperation(Operation&& op) {
        m_operations.append(std::move(op));
    }
    
private:
    double calculateOptimized(const Operation& op) {
        // Use switch instead of if-else for performance
        switch (op.type) {
            case OperationType::Add:
                return op.a + op.b;
            case OperationType::Subtract:
                return op.a - op.b;
            case OperationType::Multiply:
                return op.a * op.b;
            case OperationType::Divide:
                return op.b != 0 ? op.a / op.b : 0;
            default:
                return 0;
        }
    }
    
    QVector<double> m_results;      // Use QVector for better performance
    QVector<Operation> m_operations;
};

Q19: Write a function to detect if expression is valid.

class ExpressionValidator {
public:
    static bool isValid(const QString& expr) {
        if (expr.isEmpty()) return false;
        
        int openParen = 0;
        bool expectingOperand = true;
        bool lastCharOperator = false;
        
        for (int i = 0; i < expr.length(); ++i) {
            QChar c = expr[i];
            
            if (c.isDigit() || c == '.') {
                expectingOperand = false;
                lastCharOperator = false;
            } else if (c == '(') {
                openParen++;
                if (!expectingOperand) return false;
                expectingOperand = true;
                lastCharOperator = false;
            } else if (c == ')') {
                openParen--;
                if (openParen < 0) return false;
                if (expectingOperand) return false;
                expectingOperand = false;
                lastCharOperator = false;
            } else if (c == '+' || c == '-' || c == '×' || c == '÷') {
                if (lastCharOperator || expectingOperand) return false;
                expectingOperand = true;
                lastCharOperator = true;
            } else if (c == ' ') {
                continue;  // Ignore spaces
            } else {
                return false;  // Invalid character
            }
        }
        
        // Check final state
        if (expectingOperand) return false;
        if (openParen != 0) return false;
        if (lastCharOperator) return false;
        
        return true;
    }
    
    static QStringList tokenize(const QString& expr) {
        QStringList tokens;
        QString current;
        
        for (int i = 0; i < expr.length(); ++i) {
            QChar c = expr[i];
            
            if (c.isDigit() || c == '.') {
                current += c;
            } else if (c == '+' || c == '-' || c == '×' || c == '÷') {
                if (!current.isEmpty()) {
                    tokens << current;
                    current.clear();
                }
                tokens << c;
            } else if (c == '(' || c == ')') {
                if (!current.isEmpty()) {
                    tokens << current;
                    current.clear();
                }
                tokens << c;
            } else if (c == ' ') {
                if (!current.isEmpty()) {
                    tokens << current;
                    current.clear();
                }
            }
        }
        
        if (!current.isEmpty()) {
            tokens << current;
        }
        
        return tokens;
    }
};
